Download for Windows Open the release on GitHub

  1. Open the file

    When Oto-Setup.exe finishes downloading, open it from your browser's downloads.

Download for Android
Check the file

Make sure it's the real one

Every installer is built on GitHub from Oto's public code and carries a signed build record. With GitHub's command-line tool:

gh attestation verify Oto-Setup.exe --repo mukairyo/oto

Or compare it with SHA256SUMS.txt. Oto runs the same check on every update before installing.
